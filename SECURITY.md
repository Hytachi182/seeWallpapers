# Security policy

Treat community templates as untrusted content. Do not add filesystem, process, or unrestricted network access to the template SDK. Report vulnerabilities privately to the maintainers before public disclosure.

Use [GitHub private vulnerability reporting](https://github.com/Hytachi182/seeWallpapers/security/advisories/new). Include the affected version, reproduction steps and impact. Do not publish sensitive information in a public issue.
