Première distribution publique construite par GitHub Actions de **seeWallpaper**, créé par **Michael Ruffenach**.

### Télécharger

- **seeWallpaper-Setup-x64.exe** : installation avec raccourcis, menu contextuel du Bureau, ouverture des fichiers `.seewall` et désinstallation Windows.
- **seeWallpaper-Portable-x64.zip** : extraire tout, puis ouvrir **Lancer seeWallpaper.cmd**.
- **SHA256SUMS.txt** : empreintes des deux téléchargements.

### Fonctionnalités

- 13 scènes animées avec aperçus, personnalisation et favoris.
- Choix indépendant des écrans, duplication et extension du fond animé.
- Import, export et duplication des packages `.seewall`.
- Profils de performance et pause en plein écran, sur batterie ou lors du verrouillage.
- Page **À propos** avec le créateur et les fonctionnalités.
- Correction du chargement multi-écrans WebView2 et compatibilité avec la surface de bureau moderne de Windows.

### Installation

Windows 10 version 2004 ou ultérieure, ou Windows 11, en 64 bits. .NET est inclus. WebView2 est installé si nécessaire ; ce premier téléchargement nécessite Internet. Les treize scènes fonctionnent ensuite hors ligne.

Fermer l'ancienne application avant de changer de version. Les réglages personnels restent conservés dans `%LocalAppData%\seeWallpaper`.

### Validation et limites

22 tests .NET, 23 contrôles du cycle d'installation et 28 contrôles du ZIP réussis localement. Le moteur a aussi été testé sur trois moniteurs, avec remplacement, duplication, extension et changement de contexte DPI.

L'application et son installeur ne disposent pas encore de signature éditeur. L'installation de WebView2 sur un Windows entièrement dépourvu de ce runtime reste à valider. Le changement d'écrans à chaud actualise la vue ; la réconciliation automatique des fonds après déconnexion reste prévue.

### Correctif de packaging 1.2.1

Le script de validation crée automatiquement son dossier de rapport sur un checkout GitHub vierge. Les fonctionnalités de la version 1.2.0 sont conservées.
