Public distribution of **seeWallpaper**, created by **Michael Ruffenach**.

### Downloads

- **seeWallpaper-Setup-x64.exe**: installation with shortcuts, desktop context menu, `.seewall` opening, and Windows uninstall support.
- **seeWallpaper-Portable-x64.zip**: extract all files, then open **Lancer seeWallpaper.cmd**.
- **SHA256SUMS.txt**: checksums for both downloads.

### Features

- 13 animated scenes with previews, customization, and favorites.
- Independent display selection, duplication, and spanning.
- Import, export, and duplicate `.seewall` packages.
- Performance profiles and pauses for fullscreen apps, battery use, and session locking.
- **About** page with creator credit and available features.
- Multi-display WebView2 loading fix and support for modern Windows desktop surfaces.

### Installation

Windows 10 version 2004 or later, or Windows 11, 64-bit. .NET is included. WebView2 is installed if needed; this initial download requires Internet. The thirteen scenes then work offline.

Close the previous app before changing versions. Personal settings are retained in `%LocalAppData%\seeWallpaper`.

### Validation and limits

The 1.2.0 baseline passed 22 .NET tests, 23 installer lifecycle checks, and 28 ZIP checks locally. The engine was also tested on three monitors with replacement, duplication, spanning, and DPI-context changes.

The app and installer do not yet have a publisher signature. WebView2 installation on a clean Windows system without that runtime still needs validation. Display changes refresh the overview; automatic wallpaper reconciliation after disconnection remains planned.

### Packaging fix in 1.2.1

The validation script creates its report directory on a clean GitHub checkout. This release was built and verified by GitHub Actions. Its historical ZIP uses the launcher filename shown above. Version 1.3.0 introduces the English launcher name.
