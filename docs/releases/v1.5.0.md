# seeWallpaper 1.5.0

Display recovery, background operation, online wallpapers, application update checks, and five additional scenes bring the built-in catalog to 23 wallpapers.

- Reconcile display connections and geometry changes automatically. Disconnected independent assignments remain saved; recognized monitors restore their scene. Duplicate and Span recompute their layout.
- Windows monitor device interface identities replace session display numbers. **After upgrading, select the wallpapers for independent monitors once.** Scene customization and favorites are retained. Changed ports or docks may need another selection; ambiguous identities are not assigned automatically.
- Restore independent monitors separately, with visible and logged warnings when a scene fails.
- Keep wallpapers running in the notification area. Sign-in startup restores them silently, and installer updates retain the startup choice.
- Discover new scenes and scene updates on the Online page, with file verification before installation.
- Check application updates and open the official release download page. Application installation remains manual.
- Add Crimson Valley, Pure Cosmos, Solar System, Lunar Silence, and Robot Workshop.
- Detect machine-wide WebView2 in both registry views.

Windows 10 version 2004 or later and Windows 11, x64. .NET is included. Initial WebView2 installation requires Internet when the runtime is absent.

The app and installer remain unsigned. Installation without a pre-existing WebView2 runtime and physical monitor unplug/replug, docking, and scaling acceptance remain pending. Automated checks do not certify those scenarios. See [release readiness](../release-readiness.md) for validation evidence.
