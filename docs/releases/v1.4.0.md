# seeWallpaper 1.4.0

Five new original animated scenes bring the built-in collection to **18 wallpapers**.

- **Ninja Anime** — masked rooftop guardian, crimson moon, flowing scarf and drifting blossoms.
- **Hidden Village** — lantern-lit mountain village, tiled rooftops, waterfall mist and fireflies.
- **Shinobi Energy** — rotating energy seals, luminous ribbons and rising sparks around a shinobi.
- **Orange Ninja** — orange-cloaked guardian overlooking a golden valley, with wind-blown leaves.
- **Anime Moon Battle** — two airborne shinobi facing each other beneath a blue moon.

Find them in the **Anime** category. Preview any scene, adjust **Energy accent**, **Animation speed**, and **Atmosphere intensity**, then choose **Apply to my displays**. New built-in scenes are added to your library when this version starts.

All artwork runs offline and follows the app's pause and performance settings. The app, installer, portable launcher, and documentation remain in English.

Locally verified: 27 .NET tests, 25 installer lifecycle checks, 33 ZIP checks, and rendering/customization/pause checks for all five new scenes. Ninja Anime also passed real loading and transitions on three monitors.

## Downloads

- `seeWallpaper-Setup-x64.exe`: Windows installer with shortcuts, optional context menu, file association, sign-in startup, and uninstall support.
- `seeWallpaper-Portable-x64.zip`: extract all, then open **Launch seeWallpaper.cmd**.
- `SHA256SUMS.txt`: checksums for both distributions.

Windows 10 version 2004 or later, or Windows 11, 64-bit. .NET is included. Installing WebView2 requires Internet if it is missing. Settings remain in `%LocalAppData%\seeWallpaper`, shared by both editions.
